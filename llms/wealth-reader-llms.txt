# Wealth Reader

> Wealth Reader is a bank-aggregation API for companies: read-only access to accounts, cards, loans and investment portfolios from hundreds of banks and asset managers in 61 countries. ISO 27001 (AENOR) and authorised by Banco de España. Based in Madrid (Wealth Reader S.L.).

Use this file to discover the public documentation. Prefer the Markdown and YAML sources linked below over scraping HTML.
